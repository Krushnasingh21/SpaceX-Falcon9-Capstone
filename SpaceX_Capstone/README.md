# SpaceX Falcon 9 Capstone — corrected notebook package

## Run order
1. Open `notebooks/00_README_and_setup.ipynb`
2. Run `notebooks/01_data_collection_api_and_scraping.ipynb`
3. Run `notebooks/02_data_wrangling.ipynb`
4. Run notebooks 03–08 in order.

## Important
The original SpaceX API can return network/server errors (including HTTP 525). Notebook 01 now retries requests and stops with a clear message instead of leaving later notebooks to fail with confusing missing-file errors. If the API remains unavailable, use the course-provided SpaceX datasets and save/transform them into the expected files in `data/`; do not create empty or fabricated data files.

All data-dependent notebooks expect `data/spacex_launches_cleaned.csv` generated by notebook 02. The notebooks have not been executed against your live environment/data, so run them in order and inspect the actual outputs before using metrics or charts in your final report.
